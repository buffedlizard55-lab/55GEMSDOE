Why the old forensic explanation is withdrawn

The previous anchor report treated the sum of nearest-catalogue kernel weights at prediction pixels as TP_w. Under the metric definition, TP_w is instead the sum over truth pixels of the maximum match over predictions. The report also used the invalid closed form TP_w / (0.2*N + 0.8*|G|). Therefore its proxy DTI values, hidden-truth-size calculations, ratios, and causal narrative are not supported and have been removed from current conclusions.

Correct identity: TP_w + FN_w = |G|
Correct DTI: TP_w / ((1-beta)*TP_w + alpha*FP_w + beta*|G| + eps)
At alpha=0.2, beta=0.8: TP_w / (0.2*TP_w + 0.2*FP_w + 0.8*|G| + eps)

What would establish the claim

An actual organizer submission receipt must identify the submitted file and score, and the raster hash must match the file under analysis. Until that exists, this project cannot explain why the reported value occurred or assert that any candidate beats it. The public board snapshot alone, a file name, and a prediction are insufficient.

Project decision: the H33 score attribution is unsupported, and the retained project GeoTIFF is not cleared for download or submission.
