Critical metric correction

The identity TP_w + FN_w = |G| is valid. It does not imply TP_w + FP_w = N. Therefore the correct general form is:

DTI = TP_w / ((1-beta)*TP_w + alpha*FP_w + beta*|G| + eps)
alpha=0.2, beta=0.8: DTI = TP_w / (0.2*TP_w + 0.2*FP_w + 0.8*|G| + eps)

Several older target-size, “coverage plateau,” anchor-proxy, and greedy-objective claims used the false count-only denominator and are withdrawn. Details and a counterexample are in the results audit.
