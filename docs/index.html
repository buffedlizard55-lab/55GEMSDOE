Executive summary

A potential-field gradient ridge cannot distinguish an elongated fault/contact from a compact intrusion/vent. The RTP-magnetic (band 2) and isostatic-gravity (band 13) gradient tensors encode dimensionality and a candidate strike. A near-2-D, strike-concordant ridge should preferentially retain fault-like structure. H57-A adds a 15-pixel off-catalogue flank prior built only from the VISIBLE catalogue during holdout, based on the measured adjacency pattern in the local anchor forensics. It was tested as a new-fault prediction, not assumed to be a leaderboard improvement.

Use the existing one-scale cached stack (band 2 RTP magnetic + band 13 isostatic gravity); nearest-valid fill, robust line-axis leveling, low-pass before mirror-padded FFT derivatives, closed-form symmetric 3x3 tensor eigendecomposition, dimensionality invariant, intermediate eigenvector strike, strike agreement, plunge weight, corroborated ridge rank. H57 holdout and final writer use the same cached tensor factors and a 15-pixel quadratic off-catalogue flank prior; the candidate sensitivity run removes the cached 6-pixel footprint erosion (un-eroded edge score) to test whether a dense 5-pixel lattice registry raster leaves any unique feasible pixels. What the metric rewards

The official distance-weighted Tversky metric uses alpha 0.2, beta 0.8, and a 300 m triangular kernel.
