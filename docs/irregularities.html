Critical metric error

The identity TP_w + FN_w = |G| does not imply TP_w + FP_w = N. The correct DTI denominator is (1-beta)*TP_w + alpha*FP_w + beta*|G| + eps; at α=0.2 and β=0.8 it is 0.2*TP_w + 0.2*FP_w + 0.8*|G| + eps. All old count-only target-size, anchor-proxy, and “coverage plateau” conclusions are withdrawn. A regression test now shows the false formula fails on one truth pixel plus a nearby false positive.
