IR-55-001The repository was empty. At session start 55GEMSDOE contained a single 11-byte README.md reading “# 55GEMSDOE”. The run brief says to reuse the template's cached feature stack, evaluate_holdout.py and submission_writer.py, and to check uniqueness against a registry. High — nothing to reuse; no registry existed. Built all three shared tools here as the single implementation (no private fork) and constructed the registry by downloading 56 prior scored rasters from sibling repositories via the GitHub blob API.
IR-55-002No DrivenData credentials and no general network. The sandbox reaches only github.com, api.github.com, codeload.github.com, pypi.org and registry.npmjs.org. drivendata.org, usgs.gov, github.io and raw.githubusercontent.com all fail at the TCP layer. High — the data download page and every prior GitHub Pages site are unreachable from the build environment. Recovered the official rasters from prior repositories under the same account and verified them by content address (see Sources). Prior site content was read through a research tool with broader reach, never assumed.
IR-55-003Transcription ambiguity in the published dimensionality formula. Karimi & Kletetschka (2024) Eq. 4 renders as I = −(I₂/2)²/(I₁/2)³. Substituting the standard invariants, that normalisation reaches only 8/27 ≈ 0.296 at the pure-3-D endpoint, contradicting the same paper's statement that I = 1 there. Changing the denominator to (I₁/3)³ makes both documented endpoints exact. Medium — affects only the index's scaling, not its ordering. Implemented the endpoint-exact form, unit-tested both endpoints analytically, computed the eigenvalue ratio −λ2/λ1 alongside it, and disclosed the ambiguity here rather than presenting either as settled fact.
IR-55-004The lane brief's flight-line direction is wrong for these grids. The brief asserts east–west flight-line striping. Three independent measurements say north–south: the 1–20 km spectral annulus carries more power with its wavevector along east–west for both fields (0.104 vs 0.089 magnetic, 0.222 vs 0.166 gravity), and the 6 km-lag coherence is higher along north–south for both. Medium — masking the assumed direction would remove real structure and keep the artefact. Measured the direction first, verified the azimuth convention on a synthetic field, and masked the measured direction. Both readings are published in evidence/striping_diagnostic.json.
IR-55-005The segment-level holdout leaks. Cutting mapped traces on a 20-px lattice leaves the visible continuation of the same trace flanking every withheld piece, so a catalogue-proximity prior scores 0.4982 by gap-filling rather than by discovery. High for interpretation — that number must not be read as a forecast. Labelled the result as leakage, built no submission from it, and used the contiguous-quadrant holdout (where the catalogue prior is structurally unavailable) as the decision instrument.
IR-55-006The leakage-canary control is a definitional artefact. neg_visible_catalogue_distance reaches AUC 1.000 in folds 1–3 because it is measured against fold 0's visible set, which contains those folds' truth pixels by construction. Low — no lane feature is affected; all lane AUCs are 0.41–0.54. Documented rather than deleted, because the artefact is instructive about how quickly a catalogue-derived control becomes meaningless across folds.
IR-55-007The organiser template is not what its caption says. The problem description calls the sample submission “a sample submission that predicts total fault absence”, but the file contains 60,988 pixels equal to 1.0 and 5,106,385 equal to 0.0 — exactly the mapped-fault count. It is the existing-faults raster, not an all-zero raster. Low for us (only its grid metadata is used) but it would mislead anyone using it as a zero baseline. Used only its shape, CRS, transform and NaN footprint, all of which were re-verified against the labels raster.
IR-55-008The 3-px uniqueness rule is vacuous against dense references. A prior spacing-5 lattice with 206,895 positives puts 84.1% of any 40,000-dot set within 3 px of its dots. Medium — the rule as written would flag every submission as a duplicate. Added a uniform-random control at matched size and reported the excess over it (+0.0399 max), plus the raw statistic restricted to the 43 density-matched references (max 0.6694, under the 0.70 threshold) for the superseded 40k file. For the 160k file the same statistic is 0.8401, flagged in IR-55-030. Both readings are published.
