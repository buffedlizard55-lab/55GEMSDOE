Why the -zeros file and not the -nan twin

The official rules allow either encoding — “data outside the bounds is null or nan”. But the portal also enforces Predicted values must be in range [0, 1]. A NaN outside the footprint can fail that check depending on how the validator folds NaN into its min/max. The -zeros file has zero NaN cells and every value in [0, 1], so it cannot trip the range check. The NaN twin is provided only for comparison.
