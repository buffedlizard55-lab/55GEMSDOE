📋 How to Submit to DOE GEMS Prize

← Back to main page

Quick Summary

Download the .tif file, go to the DOE GEMS competition page, upload it, add a note, and click Submit. That's it.

📥 Download Primary Submission

Step-by-Step Instructions

1
Download the submission file

Click the download button above, or use one of these links:

  • Primary (zeros outside) — 1.6 MB
  • Alternate (NaN outside) — 2.4 MB

The file will be saved to your Downloads folder as a .tif file.

2
Go to the DOE GEMS competition

Open drivendata.org/competitions/306/competition-doe-gems in your browser.

If you don't have a DrivenData account, you'll need to create one (free) and accept the competition rules.

3
Sign in

Log in to your DrivenData account. If you haven't joined the competition yet, click "Join Competition" first.

4
Navigate to the submission page

Click "New submission" or go to the submission/upload page from the competition menu.

5
Upload the file

Click "Choose File" (or "No file chosen") in the "File to submit" section and select the downloaded .tif file.

The file must be a single-band GeoTIFF matching the submission format: EPSG:32611, 100m resolution, 3292×3730 pixels.

6
Add a note

In the "Note (optional)" field, paste:

tensor-grad-gated NMS dim-weighted RTP+grav cross-field corroboration 168854 dots 20261009 zeros

This helps you identify this submission later.

7
Submit

Click the Submit button. The platform will validate your file and show your score on the leaderboard.

Troubleshooting

❌ "Predicted values must be in range [0, 1]"

Cause: The portal detected values outside [0, 1] — typically NaN or a nodata sentinel inside the valid region.

Fix: Try the NaN outside variant instead of the zeros variant. Both have identical values inside the footprint.

Our files: Both variants have been verified: all values inside the footprint are in [0, 1], all cells are finite (zeros variant) or NaN only outside the footprint (NaN variant).

❌ Format mismatch error

Check: The file must be exactly:

PropertyRequiredOurs

✅ Successful submission

If the submission is accepted, you'll see a confirmation with your score on the public leaderboard. The score is computed against the private test set of new faults identified by experts.

Remember: the Final Prize Round re-scores against an expanded label set where experts verify predictions from ALL teams. Predictions backed by geophysical evidence (like ours) have a higher chance of being verified.
