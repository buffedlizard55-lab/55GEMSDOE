Official format contract (verified 2026-10-09)

  • Source: official problem page, submission format. The file must be in EPSG 32611 at 100 m, have the same bounds as the training data, and contain a single float32 layer.
  • Values: inside the footprint, each value must be between 0 and 1. Cells outside the bounds must be null or NaN. The page says so explicitly, so a zero-filled outside encoding does not meet the spec.
  • Entry form (user-reported screenshot text): a single-band GeoTIFF (.tif), or a .zip containing a single GeoTIFF; a short note field.
  • Limit: three submissions per week (official rules, section 3.2).
  • Repository check: the canonical grid constants in src/gems55/io55.py (EPSG 32611, 100 m, 3292 by 3730) match the official text. The authoritative organizer template is absent here, so this is not an organizer validation.

If the portal says "Predicted values must be in range [0, 1]"

The archived rasters in this repository all lie inside [0, 1], so the error from your earlier upload is unexplained (see docs/irregularities.md, IR-55-049). Check these causes against the exact file that was rejected:

  1. Any value below 0 or above 1 anywhere in the file.
  2. NaN inside the footprint (the spec allows NaN only outside the bounds).
  3. A sentinel such as -9999, or a zero fill outside the bounds (the spec requires null or NaN there).
  4. Whether the portal reads an encoding or nodata flag differently from the file's metadata; the portal's exact rule is not published.

To diagnose the failure, send the rejected file's name and SHA-256. Do not assume it matches an archived raster.

Naming and note convention (no name is assigned: no file exists)

  • Name pattern: 55gemsdoe-<lane>-<method>-<UTC YYYYMMDDThhmmssZ>-<sha256 first 8>, for example 55gemsdoe-tensor-h1n1-20261009T120000Z-1a2b3c4d. It is unique to a file and is recorded in the run card.
  • Note (140 characters or fewer): lane, method, key parameters, and status, for example tensor lane; pseudogravity tensor; kernel 300 m; holdout DTI pending; not cleared.
