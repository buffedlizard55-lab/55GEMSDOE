Submission steps

These upload steps are conditional on the banner saying OK TO DOWNLOAD AND SUBMIT. The current banner says NOT CLEARED; do not upload the current audit TIF.

  1. Check the banner above. If it says NOT CLEARED, stop. No competition slot should be used.
  2. Only after a future file is cleared, download the exact -nan.tif named on the overview and verify its SHA-256. The current NaN-outside TIF passes 11/11 local checks. The -zeros.tif diagnostic fails the strict null/NaN outside-footprint check and is not an upload candidate.
  3. Run scripts/validate_submission.py against the official template and check the run card's final-dot uniqueness and matched-mass holdout gates.
  4. Sign in to DrivenData competition 306 (this repository never stores credentials).
  5. Upload one single-band GeoTIFF (or a .zip containing one GeoTIFF). It must match the official CRS (EPSG:32611), 100 m resolution, shape (3730 × 3292), geotransform, value range [0,1], and the organizer's outside-footprint null/NaN rule.
  6. Paste the portal note from the run card into the optional note field. The official rules require a narrative explaining the extent of generative-AI use and how it contributed; this project used an AI coding/research agent, so any future prize package must disclose that use accurately.
  7. Use at most three submissions per week for feedback; before the deadline, select one final submission to count for both prize phases, as stated in the official rules. This site never uses a weekly slot.
  8. Save the submission-page receipt. Until a receipt exists, no score is ORGANIZER-CONFIRMED.
