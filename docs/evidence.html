Metric definition and correction

The official problem page defines the distance-weighted Tversky index with alpha=0.2, beta=0.8, and a 300 m triangular kernel. From TP_w + FN_w = |G|, the correct denominator is (1-beta)*TP_w + alpha*FP_w + beta*|G| + eps, or 0.2*TP_w + 0.2*FP_w + 0.8*|G| + eps for the competition parameters. The count-only denominator 0.2*N + 0.8*|G| is invalid unless a separate, generally false identity TP_w+FP_w=N is established.

A synthetic counterexample is asserted in the test suite: one truth pixel plus one exact unit prediction and one adjacent unit prediction yields TP_w=1, FP_w=1/3, FN_w=0, exact DTI 0.9375, while the invalid simplification yields 5/6. This is a synthetic metric test, not HOLDOUT-DTI.
