5. Metric algebra, verified

TP_w + FN_w = |G| exactly (measured: 0 + 60,988 on an empty prediction), so DTI = TP_w/(0.2N + 0.8|G|). The closed form reproduces the measured DTI to four decimals at N from 25,836 to 5,167,373, and uniform placement over the footprint peaks near 0.198 at N ≈ 258,000 on the catalogue proxy.

6. Segment-level holdout — measured but NOT usable as a forecast

A second holdout that withholds whole fault segments rather than whole quadrants produced much larger numbers (up to 0.4982 pooled DTI for a catalogue-annulus prior at 29,843 dots). Those numbers are reported for completeness and are flagged as leakage: splitting a mapped trace on a 20-px lattice leaves the visible continuation of the same trace flanking every withheld piece, so the task degenerates into gap-filling. See IR-55-05. No submission was built from that holdout.
