Correct DTI algebra

From TP_w + FN_w = |G|, the official denominator becomes:

DTI = TP_w / ((1-beta)*TP_w + alpha*FP_w + beta*|G| + eps)
alpha=0.2, beta=0.8: denominator = 0.2*TP_w + 0.2*FP_w + 0.8*|G| + eps

There is no general identity TP_w + FP_w = N, so 0.2*N + 0.8*|G| is invalid. A regression case with one truth pixel, a matching unit dot, and another unit dot one pixel away gives TP_w=1, FP_w=1/3, FN_w=0, and exact DTI 0.9375; the false count-only formula gives 5/6. Old target-size tables, “coverage plateau” claims, and anchor conclusions based on that formula are withdrawn.
