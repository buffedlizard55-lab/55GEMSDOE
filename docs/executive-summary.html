Executive summary: how to make a submission

Current status (2026-10-09): no file is recommended for upload. The tensor-dimensionality lane is negative on our holdout, and its files are published only for review. They are named NEGATIVE-DO-NOT-SUBMIT_….

1. What the competition accepts

Source: DrivenData problem description.

RequirementValue
FileOne single-band GeoTIFF (.tif) or a .zip containing one GeoTIFF
CRSEPSG:32611 (UTM zone 11N) — epsg.io/32611

The error "Predicted values must be in range [0, 1]" means a value outside 0–1 was present. Our writer clips values and runs a validator before writing. See irregularities.

2. Steps

  1. Create a DrivenData account, accept the rules, and get the data from the data tab (login required). Rules: official PDF.
  2. Place the three files in data/ and run python scripts/prepare_data.py. It checks the sha256 pins.
  3. Generate a candidate with a script in scripts/. Each run writes a holdout result to docs/results/.
  4. Validate: python -m gems.submission <file.tif> data/sample_submission.tif must print "all_passed": true.
  5. Uniqueness: python scripts/registry_check.py <file.tif> <registry_dir> <out.json>. Rank correlation ≤ 0.90 and overlap ≤ 70% are required (see irregularity #7 for the saturation caveat).
  6. Upload on the competition submission page: choose File to submit, then enter a unique name and a short note (≤ 140 characters, e.g. tensor-lane v1 | holdout 0.058).
  7. Limits: three submissions per week. Choose one final submission before the deadline. Disclose any generative-AI use in the narrative.
