Method and implementation limits

The repository contains a tensor-dimensionality prototype in src/gems55/. It is not a validated submission pipeline. The competition feature rasters, organizer template, cache, and registry rasters are absent in this checkout, and this review did not rebuild or run the lane.

Prototype method

  1. Read RTP-magnetic band 2 and isostatic-gravity band 13 from the competition feature stack.
  2. Fill invalid cells and apply a band-pass. The current code uses an along-axis profile-removal operation over the full raster; it has not been shown to operate independently inside verified acquisition polygons.
  3. Compute each field's FFT gradient tensor, eigenvalues/eigenvectors, a dimensionality statistic, horizontal-gradient ridges, and local strike information.
  4. Combine normalized ridge strength with near-2-D, strike-agreement, plunge, and striping factors to form a continuous score surface.
  5. Emitters produce point predictions from the score; they do not provide evidence of holdout improvement by themselves.

Known implementation limits

  • LaneConfig.block_px=64 controls robust normalization in regular pixel tiles. It is not an official GeoDAWN acquisition-block mask. The existing run-card statement that each acquisition block was processed independently was unsupported.
  • The field-preparation profile is global along the selected raster axis, not separately estimated in the official acquisition polygons. Authorized block/flight-line layers are not staged.
  • Repository-local utilities specify whole-component hide-and-recover, per-fold visible masks, and score-independent random controls. They are not certified as the authorized shared evaluator; historical results used different logic and remain invalid for promotion.
  • The greedy cover function optimizes a monotone submodular coverage surrogate. It does not account for the exact DTI false-positive term and is not a DTI optimizer.
  • Passing synthetic unit tests verifies code properties only; it is not geological validation, an official evaluator match, or a submission clearance.

Scientific interpretation

A two-dimensional tensor signature is not specific to a fault. Lithologic contacts, dikes, intrusive sheets, altered corridors, flight-line artifacts, block seams, and FFT edge effects can mimic or distort it. Geophysical signals are candidate structure indicators, not geological labels.

Required next steps after the experiment budget is explicitly reopened: obtain authorized data, validate acquisition masks and grid alignment, freeze the processing configuration, run one-feature-at-a-time leakage canaries, evaluate whole connected fault segments with buffer and exact visible-fault masking, calculate pooled HOLDOUT-DTI with the shared evaluator and a spatial 95% CI, then check surface and final-dot uniqueness. A same-evaluator holdout win is required before submission-slot promotion.

Current decision: no new experiment, no valid holdout win, no download CTA, and no submission.
